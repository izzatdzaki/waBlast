┌────────────────────────────────────────────────────────────────────────────────┐
│  💡 IMPORTANT NOTES                                                            │
└────────────────────────────────────────────────────────────────────────────────┘

    • Keep 3 terminals open:
      Terminal 1: Baileys backend (npm start)
      Terminal 2: Laravel queue worker (php artisan queue:work)
      Terminal 3: Laragon/Laravel server

    • Messages are processed asynchronously
      Messages queued → Worker processes → Sent to WhatsApp

    • Phone numbers auto-formatted
      0812... → 628... format automatically

    • QR code must be scanned
      http://localhost:3000/qr in browser to connect

    • All endpoints need API token (except health & webhook)
      Generate token: php artisan tinker → User::first()->createToken('name')

    • Logs available at
      storage/logs/laravel.log (real-time monitoring)
